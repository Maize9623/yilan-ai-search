# 一览 AI智搜

工作地图稿。2026-09-16 立档，2026-09-17 补检索降级、补充重写、外站核对和风险。产品名现为「一览 AI智搜」。

本机跨站检索，再收成一份跟搜索目的对齐的判断。

它盖在 [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) 上面，跑在这台电脑的 Chrome 和本地服务里。输入一个话题，按你勾的站去搜；国内站用登录后的真实搜索，国外站走公开检索。收回来的材料交给十一，先读完全部材料，再写成结论、导图和深度阅读。

一览不是又一个资讯聚合器，也不是对外的 SaaS。它解决的是：人要判断一件眼前的事，材料散在各站，摘要引擎又爱写成「叙事地图」或「选 / 避 / 再看」。一览把「自己找材料」和「按题目收口」放在同一块本机看板上。

产品名从「跨站智搜」收成「一览」。检索底座仍是 MediaCrawler；判断人格是十一（`board/eleven.md`）；公众号和部分 Reddit 读取复用本机「信息看板」里的 feedgrab。两套项目合并的是**阅读与判断这一层**，不是把另一个仓库嵌进来。

MediaCrawler 的许可是非商业学习协议：自用、小规模、先登录再搜。一览遵守同一边界。

## 1. 立意

信息很多，判断很少。人搜「豆包手机助手选购指南」「成都中秋活动」「国庆带老人去哪」，真正要带走的不是二十个平台摘要，而是：

- 这道题要我交什么答案（选、避、论证、决策、做法，还是只看能力）；
- 材料里哪些是近况，哪些只是半年前的背景；
- 哪些对象被多条独立材料撑住，哪些只是单帖处境；
- 结论能不能直接回答搜索词，深度阅读是不是围着这个结论在论证。

一览的立场是：

1. **材料必须自己找。** 不把模型记忆或联网摘要当成检索结果。国内站打开本机 Chrome，登录态留在 `browser_data/`。
2. **核对先于堆量。** 明显不对题、错节日、错地点、过期活动，丢掉再补，而不是写进报告充数。
3. **结论跟题目走。** 「选购指南」是购物，「助手好不好用」是能力判断，「该不该换」是决策。禁止不管题目一律写成选 / 避 / 再看，也不许被「指南」「助手」抢走购物题。
4. **时效决定采纳比重。** 近7天、近一个月可以撑「现在怎么选」；半年前只当对照。读者和十一都看见同一套标。
5. **本机、可看见、可删除。** 服务只绑 `127.0.0.1`。最近 10 次可打开，也可连机器记录一起删掉。

它不追求「把全网搬回家」，追求「这一次搜索，够不够让人做判断」。

## 2. 需求

这是当前版本认领的产品需求，也是工作地图上这个节点的验收口径。

### 2.1 检索

- 一次搜索可勾：小红书、抖音、快手、B站、微博、贴吧、知乎、公众号；国外默认不勾：Google News、Bluesky、Reddit、YouTube。
- 每站条数可调（15–200），各站也可单独改。
- 国内站共用一个本机 Chrome，顺序搜，不并行开多个浏览器，不走代理池。
- 第一次搜某站弹出**爬虫那扇 Chrome**，验证码和扫码由人点；登录态持久化。日常开着的 Chrome 不是这一扇。
- 登录和安全验证分开。`pong` 为真只说明账号还在；取详情被 HTTP 461 挡住时，页面上经常没有滑块。
- 正在搜时点「我登录好了，接着搜」只叫醒这一站马上再取，不掐掉重开。
- 详情接口被风控、页面已是笔记且没有滑块：从这页收正文。再不行，收下搜索列表的标题和封面。
- 某站卡住或空了：换策略、公开读取或补搜，不让一站失败变成整次搜索空白。
- 每站有递进梯子。A 取不到或明显不足，走 B，再走 C。
- 超时也要收下已经写出的 jsonl，不假装没搜过。
- 不默认打开 `ENABLE_GET_MEIDAS`，不声称做了 ASR 或完整看完视频。
- 不接现有日常 Chrome 的 CDP，不装验证码识别，不装 Dokobot，不绕过平台风控。

### 2.2 核对与补搜

- 搜索词里的地点、节日、事件日期，和帖子对不上，就丢掉。
- 「入门」「上门」「热门」这类词不当地名。jieba 会把「入门」标成 `ns`，不拦的话英文结果会被当成「地点对不上」丢掉。
- 搜国庆却是十年前五一、搜中秋却是去年游园会，属于明显不符合需求。
- 时效很差且对当前判断无用的，忽略再补。
- 取量按「想要的条数 + 3～8」，不再按两倍狂取。
- 取完后十一看一次缺口，只补一轮，不无限循环。
- 国外站先把中文检索词译成英文再搜；留下的条目仍按同一套核对。

### 2.3 判断与报告

- 先读搜索词要交什么，再读完全部材料，最后写结论。
- 结论必须直接回答这次搜索。形式可以是一段话、流程、数据、对象清单，或几种混合。
- 结论清单只收至少两条独立材料撑得住的对象。单帖故事进深度阅读。
- 深度阅读按论点展开（原则、品类、争议、例外），左右分栏：左边论点，右边论据、案例、配图、数据。围着结论写，不按平台一节一节摘要。
- 导图是知识 / 决策逻辑，不是六站目录。
- 各平台摘要是判断前的分站侧面，不能替代结论。
- Agent 搜索是模型知识，不是时间线。页面上收成各平台摘要下的一张参考卡，点开看模型、时间和要点，不在报告顶上整段倾倒。
- 外文材料用中文回译写报告，原文只作对照。
- 社交帖是叙事信号，不是已核实新闻。
- 现有材料够用时，不勾平台、只写要求，点「补充并重写报告」就按这句话改口，不再先问十一要不要再搜。
- 重写时顶上展开进度，补充区只留一句此刻在做什么，不堆旧对话。

### 2.4 阅读与交付

- 原文标出博主、粉丝、赞评转、时效。
- 博主名和标签像数字一样标出来。
- 配图走百度 / 360 等国内图；不把 Wikimedia / Flickr 当成已填配图留下。
- 编程、学习规划这类题配「代码 / 教程」，不配路线图、地图、玄关。
- 深度阅读左侧才配公开图，右侧保留原帖精选图。
- 补充搜索卡在整份报告之后、原始检索结果之上。
- 弹层、模块、出图有过渡；尊重系统「减少动态效果」。
- 最近 10 条，可二次确认后删除本机记录；配图缓存在本机，可查看占用并清掉。
- 报告可导出 Markdown / PDF。
- 本机密钥可新增多把，新增时标明是 AI key 还是 YouTube key，首页可切换。无 AI 模式只摊开材料，不调用模型。

## 3. 特点

### 3.1 国内站：看见爬虫那扇 Chrome

小红书、抖音、快手、B站、微博、贴吧、知乎走 MediaCrawler 的 Playwright，`channel=chrome`，独立用户目录。人可以在弹出的窗口里点验证、扫码。这不是无头黑盒，是可干预的本机检索。

「把窗口拉到前面」只通知爬虫窗口，不激活日常 Chrome。小红书取详情若被接口风控，看板会打开一条笔记；没有滑块就从这一页收，不再假装你必须过验证。

### 3.2 公众号：搜狗索引，必要时读正文

公众号不登录微信。先走本机 feedgrab 的搜狗微信公开索引。`text_source=index` 只有标题和摘要；跳到 `mp.weixin.qq.com` 读到正文才是 `public`。十一不得把索引写成已读完全文。

### 3.3 国外站：公开检索，默认不勾

| 站 | 取法 | 备注 |
|---|---|---|
| Google News | 公开新闻索引，不足时补 Bing News | 索引不是全文 |
| Bluesky | 公开帖搜索（`query=`） | 空结果时中英双语再搜 |
| Reddit | feedgrab → reddit.com JSON → 公开归档 | 一环失败换下一环 |
| YouTube | 官方 Data API v3 搜索 | 要 `YOUTUBE_API_KEY`；只有标题和简介，未见口播 |

X / Twitter 没有接。官方搜索不在便宜档，GitHub 上能搜的开源工具都要登录态，维护重，不适合做成「填个 key 就勾上」的芯片。

### 3.4 梯子，而不是死磕一个词

`tools/search_ladders.py`：A 整句，B 短词，C 核心词。当前步为空或不到目标一半，才升级。微博还有综合 / 实时 / 热门。B站并发用 `return_exceptions`，一失败不等于整站空。

### 3.5 意图语法

`board/intent_frame.py` 先认搜索任务，再决定结论标签：

| 题目 | 模式 | 标签 |
|---|---|---|
| 选购 / 购买 / 选购指南 / 买哪个 | 购物 | 选 / 不选 / 再比 |
| 推荐 / 安利 | 购物 | 选 / 不选 / 再比 |
| 避雷 / 翻车 / 别买 | 避雷 | 可留 / 避 / 还说不准 |
| 是否 / 靠不靠谱 | 论证 | 撑得住 / 撑不住 / 还说不准 |
| 该不该 / 换不换 | 决策 | 先做 / 别做 / 取决于 |
| 对比 / vs | 对比 | 更强 / 更弱 / 打平 |
| 怎么做 / 攻略 / 教程 | 做法 | 照做 / 别照做 / 缺条件 |
| 助手 / 评测 / 好用吗（且没有购买任务） | 能力 | 能用 / 别指望 / 再观察 |

「豆包手机助手选购指南」是购物，不会被「指南」「助手」写成先做或照做。「豆包手机助手」仍是能力判断。「成都美食攻略」仍是做法。

### 3.6 时效标注

`board/freshness.py` 给每条材料打标，原文列表、详情、案例气泡和十一输入共用：

| 距今 | 标签 | 采纳 |
|---|---|---|
| ≤7 天 | 近7天 | 近况 |
| ≤30 天 | 近一个月 | 近况 |
| ≤90 天 | 近三月 | 可参考（时效紧的题目降为仅背景） |
| ≤180 天 | 近半年 | 仅背景 |
| ≤365 天 | 半年前 | 仅背景 |
| 更早 | N年前 | 慎用 |
| 无时间 | 时间不明 | 降权 |

十一写报告时近况优先排在前面，全部材料都给她。旧帖和高互动旧帖都只能说明当时怎么说。

### 3.7 十一

十一是判断编辑，不是摘要机。人格在 `board/eleven.md`。默认模型是 DeepSeek。它必须：

- 先分析完全部材料，再写 `report.answer`；
- 按题目选择段落 / 清单 / 流程 / 数据 / 混合；
- 深度阅读围着这个结论展开论点、论证、论据；
- 点明依据是最近还是旧帖。

页面上「先看结论」不再只是三块色卡。可以有一段收口，下面再跟流程、表和对象清单。Agent 搜索单独成卡，不进时间线。勾无 AI 时十一整层跳过。

### 3.8 视频原文的诚实边界

抖音、快手、B站的 `video_text` 若来自官方字幕或创作者文案，按原文读。只有简介就写「未见口播原文」，不编口播。YouTube 目前只有简介。不把短视频写成小红书种草笔记，也不把长文丢掉。

## 4. 一次搜索怎么走

```text
输入话题
  → 识别意图（购物 / 论证 / 决策 / 做法 / 能力 …）
  → 按勾选平台顺序检索
      国内：本机 Chrome + 梯子 A→B→C
      公众号：搜狗索引，必要时打开原文
      国外：公开 HTTP / 官方 API
  → 核对：地点、节日、事件、明显跑题 → 丢掉再补
  → 打时效标，写入 board/runs/<任务>/
  → 十一读全部材料（近况优先排序）；可选一层 Agent 搜索作参考
  → 结论 + 导图 + 分站侧面 + Agent 参考卡 + 深度阅读
  → 可补充：只重写报告，或勾平台再提一轮
  → 本机最近 10 条可回看、可删除
```

服务：FastAPI，默认 [http://127.0.0.1:8765](http://127.0.0.1:8765)。任务目录在 `board/runs/`。配图缓存不进「最近」。

## 5. 迭代过程

这是工作地图要的那一段：这个节点怎么长成现在这样。按产品决策排，不是按 commit。

### 5.1 底座：本机跨站搜

先有 MediaCrawler 的逐站爬虫。一览要的是「人坐在前面搜一个话题」，所以做成本地页：勾平台、看进度、看刚收回的封面。约束一开始就定死——本机、可见 Chrome、登录持久化、不接日常浏览器、不破验证码、不并行、不代理池。

### 5.2 从「能搜到」到「搜对」

能收回一百条之后，问题变成错题。搜国庆出现十年前五一，搜中秋出现去年活动，推荐里还有过期年份。于是核对变成检索的一部分：地点、节日、事件日期不对就丢，再补新的。取量从「翻倍」改成「目标 + 3～8」，取完只让十一补一轮，避免六站搜十几分钟。

### 5.3 一站失败不再等于没有

B站、Reddit、公众号都出现过长时间卡住或整站空。对策不是加大超时，而是：梯子、`return_exceptions`、公众号索引兜底、Reddit 三路（feedgrab / 官网 JSON / 归档）、卡住就换策略或补搜。

### 5.4 国外站：公开检索，不把爬虫搬出国

Google News、Bluesky、Reddit、YouTube 做成可勾芯片，默认关闭。外文要回译成中文再进报告。Bluesky 空过一次，原因是接口参数写错，不是语言本身。YouTube 不走 Playwright，走官方 Data API；本机填 key 后才能勾。X 评估过，没有做成免费公开芯片的条件，先不做。

### 5.5 报告：先认题目，再写结论

早期结论容易不管搜索词，一律「选 / 避 / 再看」，或「先做 / 照做」。选购指南被「指南」「助手」认成教程或能力判断。后来把任务词抽成意图语法，购物词压过指南 / 助手；十一被要求先读完全部材料，再交一段直接回答题目的结论；深度阅读改为围着结论论证，而不是六站摘要。

### 5.6 阅读：材料要能被采用

原文互动数据归位：博主和粉丝在右上，赞评转留在标题下。博主高亮曾被字数截断，加长名单后中文名才能标上。配图坚持国内图库，不把 Wikimedia 当已填结果。列表、详情、案例都打上时效，让读者自己决定信多少。

### 5.7 产品合并：就叫一览

两个本地项目要合成一个阅读入口。名字改成一览，去掉「跨站智搜」。首页左右布局：左边搜索和平台，右边「怎么搜」气泡。最近开放到 10 条，删除要二次确认，连 `board/runs/` 里的任务一起去掉。翻阅加上弹层、果冻和出图渐变，按交付物来做，不是装饰。

### 5.8 本机配置和阅读入口

首页「本机已就绪」下可以换人格、换 key、看缓存。新增 key 时选 AI 还是 YouTube。最近会话上移，第一屏十个。报告写完后，补充搜索放在报告和原始结果之间，避免人还没看完结论就被带去改方向。

### 5.9 核对词、外站和配图

jieba 把「入门」标成地名后，Google News / Reddit / YouTube 几乎被滤光。后来「入门」「上门」「热门」进了假地名表，外站用英文检索词。编程题的配图不再跟「路线 / 规划」去搜地图。Agent 搜索从顶上的模型倾倒，收成各平台摘要下的一张参考卡。

### 5.10 小红书：登录好了，详情仍可能被挡

小红书列表接口常常能拿到二十来条，取正文走 `/api/sns/web/v1/feed` 时回 HTTP 461 Verifytype=124。首页和已打开的详情页看起来都正常，没有滑块。早先看板把「接着搜」做成掐掉重开，爬虫 Chrome 被带乱，第二次连 `ConnectError`；后来改成叫醒这一站。详情页已经打开且没有验证时，从页面收 `__INITIAL_STATE__`；再不行收下搜索列表。配图字段里的空地址曾把整站写成失败，已修。

账号侧：专用 Chrome 连续打签名接口，几小时就会要重新登录，移动端也可能被踢下线。这是平台风控，不是看板漏登。专用搜索号比把日常号绑进爬虫更稳，也没法从产品里「修好」。

### 5.11 补充重写要看得见

只写要求、不勾平台，直接按现有材料重写，不再先让十一决定要不要再搜。点下去之后顶上展开进度和秒数，补充区只留一句当前动作。旧的 refine 对话不再堆在那里。报告写完再收起过程。

### 5.12 还没做、也不假装做了的

- X / Twitter 检索。
- YouTube 口播 / 官方字幕（免费搜索 API 没有）。
- 完整评论默认关闭；打开也受条数上限。
- 不把社交热度写成官方统计。
- 不破解小红书 461，也不保证详情接口一定松开。

## 7. 启动

本机要有仓库的 Python 环境和 Google Chrome。

```bash
cp board/.env.example board/.env
```

`board/.env` 至少要有 DeepSeek key。勾 YouTube 再加 `YOUTUBE_API_KEY`。不要提交 `.env`。

```bash
uv sync
.venv/bin/python board/server.py
```

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

第一次搜某个国内站会弹出**爬虫 Chrome**。在那个窗口登录，回到页面可以点「我登录好了，接着搜」。正在搜时这个按钮只叫醒当前这一站。登录态在 `browser_data/`。各站共用一个爬虫 Chrome，所以是一个接一个搜。第一次全登录，可能要十几分钟。

小红书建议用专用搜索号。日常号绑进爬虫后，网页和手机都可能被踢下线；详情接口仍可能 461，页面上却看不到验证。

YouTube 官方搜索免费，但每天大约 100 次搜索调用。一览勾一次通常只打 1 次，梯子最多大约 3 次。额度按太平洋时间零点重置。超额当天 YouTube 会空，其它站继续。

## 8. 它故意不做的事

- 不对外提供服务，不接现有日常 Chrome。
- 不自动过验证码，不接代理池，不并行开浏览器。
- 不绕过小红书 461 / 其它站的安全验证，不把日常 Chrome 拉到前面冒充爬虫窗。
- 不默认抓国外站，不把 X 做成「能勾就当稳定源」。
- 不声称看完了视频或做了语音转写。
- 不把索引、简介、社交帖写成已核实事实。
- 不把 Wikimedia / Flickr 当国内配图结果留下。
- 不把另一个一览仓库嵌进这个仓库。

十一的人格在 `board/eleven.md`。改结论语法，改那份档案和 `intent_frame.py`，不要只改页面上的三块色卡。

## 9. 风险（工作地图要盯的）

这些不是「再改一版页面就能消失」的缺陷。有的已经有降级，有的只能接受。

### 9.1 小红书：详情接口风控（当前无解）

- **现象**：已登录（`pong True`），搜索列表能拿到二十来条，取详情 HTTP **461 Verifytype=124**。爬虫窗里可能是首页，也可能已经打开一条笔记，**都没有滑块或验证码**。
- **原因**：风控打在签名后的 feed / 详情接口，不是登录过期，也不是页面没渲染。看板不能、也不会去解验证、改签名或借用日常 Chrome 的 cookie。
- **人能做的**：用专用搜索号；在爬虫窗里手过真正弹出来的滑块；等接口自己松开后再取正文。
- **产品降级**：详情页已打开且无验证 → 从页面收 `__INITIAL_STATE__`；再不行 → 留下搜索列表的标题、封面、链接。正文会短，这一站不必显示「没搜到」。
- **账号连带**：专用 Chrome 连续打接口后，几小时就要重新登录，手机端也可能被强制下线。把日常号绑进来，等于把常用账号送进风控。这不是漏登。

### 9.2 同类：看得见的验证，和看不见的接口墙

| 站 | 常见形态 | 人怎么过 | 暂时做不到 |
|---|---|---|---|
| 小红书 | 列表通、详情 461，页面常无弹窗 | 爬虫窗里若有滑块就过；没有就等降级 | 解开 461 |
| 抖音 / 快手 | 搜索页或登录页滑块、验证 | 把爬虫窗拉到前面自己过 | 自动拖滑块 |
| 微博 | 安全验证页 | 同上 | 自动过 |
| 公众号 | 搜狗反爬、验证码 | 换篇、公开索引兜底 | 保证篇篇有正文 |
| 知乎 / 贴吧 / B站 | 登录过期、限流 | 再登、梯子、降低并发 | 保证稳定满额 |

原则一样：人过验证，程序等；等不到就降级，不装识别、不穿日常浏览器。

### 9.3 检索和核对

- 国外公开接口会空、会偏。英文检索和假地名表已经补过一刀，「入门」不再当地名；Bluesky 光搜 Python 仍可能混进玩笑帖。
- YouTube 官方搜索按天限额（大约 100 次），超额当天这一站空，其它站继续。
- 地点 / 节日核对会误伤；假地名表要跟着真实错例加，不能指望 jieba 的 `ns`。

### 9.4 本机和账号

- 爬虫 Chrome 和日常 Chrome 不是同一扇。点「把窗口拉到前面」若拉错，人会以为「验证在日常首页」，其实那一页本来就没有验证。
- 密钥和人格只存在这台电脑。`keys.json`、`.env`、`browser_data/`、`board/runs/` 不要提交、不要同步到别人的机器。
- 社交平台随时改接口。一览的承诺是「这一次搜索够不够判断」，不是「某站永远满额」。

工作地图上可以把 9.1 标成**接受的风险**：小红书正文不稳定，列表和页面降级可用；不要排期「打穿 461」。
